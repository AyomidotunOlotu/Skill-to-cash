# Skill-to-Cash

Student Income Blueprint: a multi-page static site for Nigerian students (plain HTML, CSS and JavaScript, no build step).

| Page | File |
|---|---|
| Home | `index.html` |
| Pick Your Skill | `pick-your-skill.html` |
| Free Resources | `free-resources.html` |
| Build Your Portfolio | `build-your-portfolio.html` |
| Find Clients & Close Deals | `find-clients.html` |
| 30-Day Roadmap | `roadmap.html` |

Shared styles live in `assets/css/styles.css` and shared scripts in `assets/js/main.js`.
Preview locally with `python3 -m http.server` and open http://localhost:8000/.
